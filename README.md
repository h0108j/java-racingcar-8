## ⚙ 기능 목록

### 1️⃣ 입력값 처리

1. 경주할 자동차 입력
    - `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)` 출력
    - 쉼표`,`를 기준으로 구분
    - 5자 이하만 가능
    - 쉼표를 제외하고 따로 문자를 제한하지 않음
    - 최대 자동차 수는 10대로 하며, 초과할 경우 예외 발생
    - 자동차 이름이 중복으로 입력될 경우 예외 발생
2. 시도할 횟수 입력
    - `시도할 횟수는 몇 회인가요?` 출력
    - 최대 시도 횟수는 1000회로 하며 초과할 경우 예외 발생

### 2️⃣ 전진 실행

1. 각 자동차 별 무작위 값(0~9 사이) 설정
    - `camp.nextstep.edu.missionutils.Randoms.pickNumberInRange()`를 활용
2. 값이 4 이상인 자동차만 전진
3. 실행 결과 출력
   - `실행결과`<br>
     `{자동차 이름1} : {총 전진 횟수만큼 ‘-’ 출력}`<br>
     `{자동차 이름2} : {총 전진 횟수만큼 ‘-’ 출력}`<br>
   `…`<br>
     양식으로 출력
4. 1번~3번 내용을 시도 횟수만큼 반복

### 3️⃣ 최종 우승자 출력

- 총 전진 횟수가 가장 많은 자동차 이름을 `최종 우승자 : {자동차 이름}` 양식으로 출력
- 공동 우승의 경우 쉼표 후 띄어쓰기로 구분 `최종 우승자 : {자동차 이름1}, {자동차 이름2}`
